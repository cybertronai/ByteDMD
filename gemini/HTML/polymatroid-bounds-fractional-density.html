3. The Theorem: True LP $\ge$ Fractional Splitting

If you fix the _extract_intervals bug so both algorithms evaluate the exact same trace, which bound is tighter?

We can formally prove that the True LP (polymatroid) is mathematically guaranteed to be strictly tighter (higher) than the Fractional Splitting (static_opt_lb) ALWAYS.

The Proof:

Let $M_c$ be the true max weight of a $c$-colorable subgraph.

Let $\rho_{(i)}(t)$ be the $i$-th highest variable density at time $t$.

Because any valid $c$-colorable subgraph can have at most $c$ overlapping intervals at any given nanosecond, the absolute maximum weight it can accumulate over time is strictly bounded by the integral of the top $c$ densest variables:

$$M_c \le \int \sum_{i=1}^c \rho_{(i)}(t) dt$$

If we substitute this upper bound of $M_c$ into the Discrete Calculus LP identity:

$$\text{LP Cost} \ge \int \left[ \sum_{c=1}^\infty \left(\sqrt{c} - \sqrt{c-1}\right) \big( R(t) - \sum_{i=1}^{c-1}\rho_{(i)}(t) \big) \right] dt$$

At any time $t$, $R(t) - \sum_{i=1}^{c-1} \rho_{(i)}(t)$ is exactly the sum of the remaining densities: $\sum_{k=c}^{\infty} \rho_{(k)}(t)$.

If we swap the order of summation, the inner sum telescopes perfectly, leaving just $\sqrt{k}$:

$$\text{LP Cost} \ge \int \left[ \sum_{k=1}^\infty \rho_{(k)}(t) \sqrt{k} \right] dt$$

This right-hand side is EXACTLY the formula for your static_opt_lb!

Because it relaxes a constraint, the floor it finds is slightly lower.
